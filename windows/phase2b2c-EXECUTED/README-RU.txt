RU-PROBE: проверка VPN с этого компьютера (всё включено, ничего не устанавливается)
==================================================================================

Программа Xray (официальная версия 26.10.31) уже лежит в папке bin.
Устанавливать ничего не нужно, права администратора не нужны, из интернета ничего не скачивается.

ПОДГОТОВКА
  1. Правый клик по zip > Свойства > галочка "Разблокировать" (если есть) > ОК.
     Затем правый клик > "Извлечь все". Появится папка ru-probe.
  2. Проверить, что есть файл ru-probe\bin\xray.exe (антивирус иногда его удаляет — тогда сообщить).
  3. Открыть ru-probe\links.txt в Блокноте, вставить в конец строки vless:// , сохранить.

ШАГ 1 (около 15 минут): двойной клик 1-RUN-TUNNEL-TEST.cmd. Дождаться надписи Finished.

ШАГ 2 (лучше ближе к вечеру): двойной клик 2-START-MONITOR.cmd
  Раз в 2,5 минуты одна строка:  + работает   ~ частично   x не работает   line = интернет офиса
  Оставить минимум на 3 часа, включая вечер (19:00-23:00).
  Выходить из удалённого рабочего стола крестиком. НЕ нажимать "Выйти".

ОСТАНОВИТЬ: двойной клик 3-STOP-MONITOR.cmd (или Ctrl+C в окне монитора).
  Окно закрылось или ПК перезагрузился — снова запустить 2-START-MONITOR.cmd: будет новый файл.
  Два монитора сразу не запустятся; если он уже работает, появится подсказка, что делать.

ПРИСЛАТЬ все файлы из папки ru-probe\evidence (ключей в них нет).
  После тестов удалить строки vless:// из links.txt.
