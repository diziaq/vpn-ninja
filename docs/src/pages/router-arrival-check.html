Router arrival check: GL.iNet GL-MT3000 (Beryl AX)

Check every unit in two stages: five minutes at the pickup counter with the box still closed, then about thirty minutes at home on the factory firmware. Keep the units that pass every step; return the rest within the return window. Flash OpenWrt only after a unit has passed, and only on the main unit first.

What to bring

  • Your phone, charged (photos, marketplace app with the pickup code).
  • This page, printed or on the phone; a pen for the record sheet.
  • At home: a USB-C charger of 5 V / 3 A (15 W) or more and a USB-C cable, a laptop or phone with Wi-Fi. An Ethernet cable is optional.

The flow

B. At home, factory firmware (per unit)

No internet needed. Do not plug anything into the WAN port yet. Check one unit at a time so labels and results do not get mixed up.

  1. B1. Power. Plug the USB-C cable into a 5 V / 3 A charger. The LED lights, then settles after 1–2 minutes. A weak phone charger causes reboots that look like a fault.
  2. B2. Wi-Fi from the label. On the laptop or phone, find the network named on the label (GL-MT3000-xxx and GL-MT3000-xxx-5G). Connect with the password from the label. Both 2.4 and 5 GHz should appear.
  3. B3. Admin page. Open http://192.168.8.1 in a browser. A GL.iNet setup page appears: choose a language and set an admin password (write it on the record sheet). Skip or decline any cloud account (GoodCloud).
  4. B4. Model and MAC. On the overview or system page, read the model and the MAC address. Model must be GL-MT3000; the MAC must match the label. Different interfaces may differ from the label only in the last one or two characters; that is normal.
  5. B5. Hardware check (strongest test). From a Mac or Linux terminal while connected to the router's Wi-Fi (Windows: PowerShell has ssh too). The password is the admin password from B3. 
    ssh root@192.168.8.1
    Then, on the router: 
    ubus call system board
free -m
cat /proc/device-tree/compatible; echo
cat /proc/gl-hw-info/country_code; echo
    Expected: "model": "GL.iNet GL-MT3000" and "board_name": "glinet,gl-mt3000"; free -m total about 490–500 MB (512 MB RAM minus reserved); the compatible line names glinet,gl-mt3000 and mediatek,mt7981; the country code is not CN (if it is, or the file is missing, note it for B7). Type exit to leave.
  6. B6. Wired port. Plug the laptop into the LAN port with the Ethernet cable (Wi-Fi off). The admin page at 192.168.8.1 must open over the cable too.
  7. B7. Global or CN version. In the admin page's left menu, look for a VPN section (OpenVPN, WireGuard). Present = Global: can be MAIN. Missing = CN version (GL.iNet removes VPN from it): keep it only as SPARE, and return it if a Global unit is easy to get within the window. We replace the factory software with official OpenWrt anyway, so GL's missing VPN menu does not matter to us; forum users report OpenWrt works on CN units, but GL.iNet does not confirm it and Wi-Fi limits there are unknown. A CN unit becomes MAIN only after we flash it and Wi-Fi works on 2.4 GHz and 5 GHz channels 36–48.

Why B5 is decisive. A different board cannot report glinet,gl-mt3000 together with a MediaTek MT7981 and 512 MB. Later, the official OpenWrt image is built for exactly this board and refuses to install on anything else: that is the final proof, done only on the unit you keep as MAIN.

Expected values for B5 come from how GL.iNet firmware (OpenWrt-based) reports this board; the exact free-memory figure varies by a few MB with the firmware version. If a value differs, photograph the screen and ask before returning.

Typical mistakes

Accepting before looking

Once you confirm the pickup code and leave, refusing turns into a return. Look at the box and the label at the counter.

No photos

Without photos of the sealed box and the label, a dispute about "used" or "wrong model" is your word against the seller's.

Throwing the box away

Returns usually need the full packaging. Keep everything until the return window closes.

Flashing too early

Installing OpenWrt before the checks, or on the spare, can make a return harder. Flash only the MAIN unit, after it passed, and only when we start the router setup.

Weak charger

A 5 V / 1–2 A phone charger makes the router reboot under load. It looks like a faulty unit but is not. Use 5 V / 3 A (15 W) or more.

Wrong port

The WAN port (2.5G) is for the incoming internet; the laptop goes into LAN. Nothing needs the WAN port during this check.

Returning over a MAC "mismatch"

The Wi-Fi, LAN and WAN interfaces can show MACs that differ from the label in the last one or two characters. That is normal; a completely different MAC is not.

Cloud account and weak password

Do not bind the router to GoodCloud and do not keep a short admin password. We set our own configuration later; cloud management stays off.

Mixing up units

Check one unit at a time and stick MAIN / SPARE on it immediately. Two identical boxes are easy to swap.

Returning with your password on it

Before sending a unit back, hold the reset button about 10 seconds so it returns to factory state.
